THE PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Customer Side:
- Students and working professionals living
  away from home struggle to find affordable,
  hygienic, homemade food daily.
- Existing food apps (Swiggy, Zomato) are
  restaurant-focused, expensive, and
  per-order only — no daily meal plans.
- No subscription-based homemade tiffin
  platform exists in Nepal.

Home Cook Side:
- Talented housewives and home cooks are
  invisible beyond their neighbourhood.
- They rely entirely on word of mouth.
- Tiffin agencies take 35–80% cuts leaving
  cooks with very little earnings.
- Many mothers have free time and cooking
  skills but no digital platform to monetize.
- No awareness or access to digital tools.
- No financial independence or income tracking.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CORE VALUE PROPOSITION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Subscription-first model: customers commit
  weekly or monthly — not per order.
- Hyperlocal discovery: find verified home
  cooks nearby on a map.
- Empowers housewives to earn independently
  using simple, non-technical interface.
- Transparent pricing: meal price set by cook,
  delivery cost shown separately at checkout.
- Trust-based: ratings, reviews, verified
  cook badges build community trust.

TARGET USERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Primary Customer:
  Students & hostelites (18–25 years)
  - Living away from home
  - Need affordable, hygienic daily meals
  - Budget-conscious

Secondary Customer:
  Working professionals (25–40 years)
  - No time to cook lunch
  - Prefer home-style over canteen food

Service Provider:
  Home Cooks / Housewives (25–55 years)
  - Currently serve 5–8 customers via
    word of mouth
  - Want to scale digitally
  - Mostly women, non-technical users

CORE FEATURES — MUST HAVE (MVP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Authentication:
  ✓ Register with role selection
    (customer or home cook)
  ✓ Login with email + password
  ✓ JWT token session management
  ✓ Forgot password flow

Customer Features:
  ✓ Browse nearby home cooks on map
  ✓ View cook profile, menu, ratings
  ✓ Subscribe weekly or monthly meal plan
  ✓ Pay via eSewa / Khalti / Bank QR / COD
  ✓ Real-time order status tracking
  ✓ Skip a day / pause subscription
  ✓ Rate and review meals after delivery
  ✓ Push notifications for order updates
  ✓ In-app chat with cook via Socket.IO
  ✓ Student discount offers on subscriptions

Cook Features:
  ✓ Create cook profile
    (kitchen name, food type, description)
  ✓ Upload daily menu with meal photos
  ✓ Set meal price, availability, capacity
  ✓ Accept or reject incoming orders
  ✓ Update order status in real time
  ✓ View daily earnings dashboard
  ✓ Holiday mode (notify subscribers)
  ✓ Cook Story page
    (photos, bio, ratings visible to customers)

Admin Features (Web Panel):
  ✓ Verify and approve cook profiles
  ✓ Monitor platform activity
  ✓ Handle complaints and disputes
  ✓ Track cook listing fees and premium badges
  ✓ View platform-wide analytics

USER STORIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
As a student, I want to find a nearby home
cook so I can get affordable daily tiffin
without going to a restaurant.

As a home cook, I want to post my daily menu
and receive orders so I can earn income from
my cooking skills.

As a customer, I want to track my order in
real time so I know exactly when my food
will arrive.

As a cook, I want to manage my subscriptions
and earnings digitally so I don't need a
middleman.

As an admin, I want to verify cooks before
they go live so customers trust the platform.
