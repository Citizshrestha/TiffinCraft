# Render Environment Variable Checklist

Variable **names only** — no values in this file, ever. It is committed to the
repo as a checklist; secrets live only in Render's dashboard and your local
`.env` (which is gitignored).

Derived by scanning every `process.env.*` reference in `backend/` (excluding
`node_modules`). Set these under **Render → your service → Environment**.

---

## ⚠️ Three name traps — read before you start

These will silently half-break the app if you copy from a generic guide:

| Wrong name (common guide) | Correct name (what this code reads) |
|---|---|
| `SMTP_PASSWORD` | **`SMTP_PASS`** — `utils/emailService.js:13` |
| `ESEWA_PRODUCT_CODE` alone | also needs **`ESEWA_EPAY_PRODUCT_CODE`** — different eSewa product |
| `ESEWA_SECRET_KEY` alone | also needs **`ESEWA_EPAY_SECRET_KEY`** |

`ESEWA_*` and `ESEWA_EPAY_*` are two **separate** eSewa integrations
(Intent Payment vs ePay v2). Subscription and order checkout run on **ePay v2**,
so the `ESEWA_EPAY_*` set is the one that must be right.

---

## 1. Required — the server exits at boot without these

`server.js` runs a preflight and calls `process.exit(1)` if any are missing.

| Name | Where to get it |
|---|---|
| `DB_HOST` | TiDB Cloud → cluster → **Connect** dialog |
| `DB_USER` | TiDB Cloud Connect dialog. Must include the cluster prefix (`xxxxxxxxxxxxxxx.root`) |
| `DB_PASSWORD` | TiDB Cloud Connect dialog → **Generate Password**. Copy from the dialog, never retype |
| `DB_NAME` | The database you migrated into (`tiffincraft`) |
| `JWT_SECRET` | Yours to invent. Long random string. **Changing it logs out every existing user** |

## 2. Required for a correct production deploy

| Name | Where to get it / what to set |
|---|---|
| `DB_PORT` | TiDB Cloud Connect dialog (`4000`) |
| `DB_USE_SSL` | Literal `true`. TiDB's public endpoint refuses plaintext |
| `NODE_ENV` | Literal `production`. **See the warning below** |
| `PUBLIC_BASE_URL` | Your live Render URL, no trailing slash. Needed for eSewa redirect + callback URLs |
| `CLIENT_URL` | Admin dashboard origin (the Vercel URL). Comma-separated list allowed |

> **`NODE_ENV=production` is a switch, not a label.** It disables every
> sandbox/dev fallback in `utils/esewaClient.js` and `utils/esewaEpayClient.js`.
> If you set it without also setting all four `ESEWA_EPAY_*` variables below,
> the server still starts but signs payment forms with `null` — checkout breaks
> silently. The boot preflight warns about exactly this.

> **Do NOT set `PORT`.** Render injects it. The code already reads
> `process.env.PORT` and binds `0.0.0.0`.

| Name | Where to get it |
|---|---|

| `ESEWA_EPAY_STATUS_URL` | Same source — the transaction-status endpoint used for server-side re-verification |
| `ESEWA_EPAY_PRODUCT_CODE` | eSewa merchant panel (your live merchant code) |
| `ESEWA_EPAY_SECRET_KEY` | eSewa merchant panel — signing key |

## 5. Firebase (FCM push notifications)

Pick **one** row. Unset = push notifications off; the API still works.

| Name | Where to get it |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT_JSON` | **Recommended for Render.** Firebase Console → Project Settings → Service Accounts → Generate new private key. Paste the **entire JSON file contents** as this one value |
| `FIREBASE_SERVICE_ACCOUNT_PATH` | Local development only — a filesystem path. Useless on Render |
| `FIREBASE_PROJECT_ID` + `FIREBASE_CLIENT_EMAIL` + `FIREBASE_PRIVATE_KEY` | Alternative: the three fields pulled out of that same JSON |

## 6. SMTP (Brevo) — verification emails, cook approvals, OTP

| Name | Where to get it |
|---|---|
| `SMTP_HOST` | Brevo → SMTP & API → SMTP tab |
| `SMTP_PORT` | Brevo (`587`) |
| `SMTP_USER` | Brevo SMTP login |
| `SMTP_PASS` | Brevo **SMTP key** — not your account password. Note the name: `SMTP_PASS` |
| `SMTP_FROM_EMAIL` | A sender address verified in Brevo |
| `SMTP_FROM_NAME` | Display name, e.g. `TiffinCraft` |

| `BREVO_API_KEY` | Brevo -> SMTP & API -> **API keys** tab (starts `xkeysib-`) |

**`BREVO_API_KEY` is required on Render, not optional.** Free Render web services
block outbound traffic to SMTP ports 25/465/587
([Render changelog](https://render.com/changelog/free-web-services-will-no-longer-allow-outbound-traffic-to-smtp-ports)),
so nodemailer times out after ~8s and every email fails — password-reset codes,
registration OTPs, cook-approval mail. With this key set, `utils/emailService.js`
sends through Brevo's HTTPS API instead and SMTP is only the fallback.
Note it is the **API key**, a different value from the SMTP key in `SMTP_PASS`.

`SMTP_SECURE` appears in the local `.env` but **is not read anywhere** —
`emailService.js` hardcodes `secure: false, requireTLS: true`. Skip it.

## 8. Google OAuth — optional

Skipped cleanly if unset (`config/passport.js:27` guards on it, and also
ignores the literal value `placeholder-client-secret`).

| Name | Where to get it |
|---|---|
| `GOOGLE_CLIENT_ID` | Google Cloud Console → APIs & Services → Credentials |
| `GOOGLE_CLIENT_SECRET` | Same screen. **Not currently in the local `.env`** |
| `GOOGLE_CALLBACK_URL` | Must point at the Render URL and be whitelisted in Google Console |

## Do NOT set these on Render

| Name | Why |
|---|---|
| `PORT` | Render injects it |
| `LOCAL_DB_HOST`, `LOCAL_DB_PORT`, `LOCAL_DB_USER`, `LOCAL_DB_PASSWORD`, `LOCAL_DB_NAME` | Read only by `scripts/migrate_local_to_tidb.js`, which runs from a developer machine against local MySQL |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`, `ADMIN_PHONE` | Read only by `seed-admin.js`, a one-off local script |
| `ESEWA_MOCK_MODE` | Dev-only escape hatch |
| `DEBUG_AUTH` | Local debugging only |
